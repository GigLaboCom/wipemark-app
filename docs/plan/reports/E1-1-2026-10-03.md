## Departures from the spec A, each with its basis

- **`UnicodeData.txt` cross-check (D18).** A §3.2 expects a header that
  does not exist; the file is bound to `Scripts.txt` by its assigned
  set instead (G2). Blind spot: a release that assigns nothing new.
- **`.gitattributes` patterns (D25).** Anchored paths; `ucd/*.txt`
  matched nothing from the root. `git check-attr` prints `unset`/`unset`
  for both data paths, `unspecified` for `ucd/README.md`, `text: unset`
  for `fixtures/text/x`.
- **Unit tests read `ucd/` (D24).** Lookups are `pub(crate)`; their
  tests are unit tests with `include_str!`.
- **Confusables without the block clause (D22).** 358 sources, 493
  members of H, 306 reverse entries; restoring the clause turns four
  tests red (above).
- **`NormalizationTest.txt` first line.** A §3.2 says `build.rs` does not
  read it; it reads line 1 and nothing more, so a stale test file fails
  the same version gate as a stale table file.
- **Table shapes (§4.8.9).** `char` where a `char` is returned; a pool
  plus `(offset, length)` for decompositions.
- **`name_of` names the D19 ranges (§4.11).** U+1BCA0..U+1BCA3 and
  U+1D173..U+1D17A keep their UCD names: they are default-ignorable,
  so removing them from `NAME` alone would label assigned characters
  `<reserved-…>`; doing it properly needs D19's list in three places.

## Deviations from the document, and why

- **`script.rs` carries a test-only `pub(crate) mod tests` exporting
  `ALL: [Script; 56]`.** `script_of_matches_scripts_txt_for_every_code_point`
  (in `tables.rs`) folds by matching against `as_str()` of the named
  variants, which needs the variant list; `every_script_but_other_has_code_points`
  needs it too. One list, guarded by the `ordinal` match of
  `class.rs:173-193` plus `all_lists_every_variant_once_in_order` (one
  test the document does not name). It is `#[cfg(test)]`, so it is not
  a crate item in any build that ships, and the contract's "no
  `Script::ALL`" holds.
- **`ccc` and `script_of` use `partition_point`** to find the range
  containing the code point instead of a `binary_search_by` closure;
  the semantics are §4.9's ("searches `CCC` like a range table").
- **The generated file's one non-ASCII character** (an em dash in the
  `UNICODE_VERSION` doc comment) was replaced with a comma, so the
  generated source is pure ASCII.
- **The `First`/`Last` mutation** of §5.2 cannot reach its tests while
  G2 is live; recorded above with G2 disabled for the probe.
- No change to the module map or to any interface of README §3.2–3.3.

## What the next document should know

- **E1-2.** `is_default_ignorable` is true for the D19 ranges and for
  reserved code points; `is_rtl` is true for U+200F and U+061C;
  `is_space_separator` includes U+0020; `script_of` returns `Inherited`
  for marks and ZWJ/ZWNJ. `is_variation_selector` includes U+180B..D
  and U+180F; `is_standardized_variant` knows no FE0E/FE0F pair (there
  are none in `StandardizedVariants.txt`), so emoji VS16 must be kept by
  `Emoji=Yes`.
- **E1-3.** `decomposition` is the full NFKD mapping, unordered; Hangul
  is not in any table (G6 guarantees it). `NormalizationTest.txt` is
  committed whole, six parts. `UNICODE_VERSION` is already re-exported;
  E1-3 leaves it.
- **E1-4.** `confusables_with(t, s)` returns every twin, including
  decomposable ones (U+FF41 in Latin `a`, U+03F2 in Greek `c`) — filter
  with `decomposition(x).is_none()` (D42). `confusable_target` is
  `None` for a prototype. Skeletons drop case (U+0049 → U+006C).
- **Every later document.** A probe that edits `build.rs` and is undone
  by copying an *older* file back can leave Cargo running the stale
  compiled build script (the restored file's mtime is older than the
  binary). Restore with a fresh mtime (`cp`, not `cp -p`), or `touch
  build.rs`.
