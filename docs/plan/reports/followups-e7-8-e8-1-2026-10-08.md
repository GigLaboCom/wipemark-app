## Left open

- A path swapped for a pipe in the instant between the header reader's check and its open still blocks that one open — on the background executor or the command line's thread, never on the thread that draws. std has no portable non-blocking open without `libc`, which `wipemark-models` does not take.
- `models list` writes a moved identity back only into a database at this build's schema (D404); an older one is left as it is and the file is read again until the application migrates it.
- The speech words are a list (`gguf::SPEECH_WORDS`); a speech model whose name, type and tags say none of them is still offered, as before.
