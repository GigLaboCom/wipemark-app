# E4-6c — the rewriting templates and the pivot, configured through widgets: report

signature and its `Laid` values, and refuses exactly what it refused before
E4-6c: it now asks the one rule, `row::admit` (D330), with **no** window.

on the page (it passes the window of the model on duty) and in
`row::lay_over_within(overrides, rows, ctx_len)`. *Update, 2026-10-08:* the

("Templates against the engine's window on the CLI and over MCP"):

## Decisions

- **D330 — one rule, `row::admit`.** Whether an override may be stored is
  `validate` beside the other turn of its step as it will be used, with the
  row's own `based_on` (a stale one is warned about) and the window when
  the surface knows it; errors refuse, warnings do not. The page's Save
  and `lay_over` ask it; `row::admit_adaptation` is the same plus the
  source's variables. `lay_over` passes no window (its refusals are
  unchanged); `lay_over_within` passes one. *Why:* two rules drift, and the
  window is known on the page today and on the MCP road with one call.
- **D331 — the pivot is a persisted preference.** `rewrite.pivot` is in
  `config::PERSISTED` with `Setting::RewritePivot` on the Prompts section;
  "by the document's language" deletes the row (no row is D60's default);
  a value this build cannot use reads as the default and stays until a
  choice replaces it. `prompts.*` stay dynamic keys outside it. *Why:* a
  fixed key with a widget is a preference and the gates should see it.
- **D332 — the check runs the whole tactic.** Over the fixed sample of the
  language the slot's step writes for (for `back_translate` step 1, the
  language whose default pivot the slot's language is), seed 0, the job's
  default options for the executor on duty; Layer A, every guard's own
  verdict, then `job::verdict`. Through `Preferences::rewriter` — a clone
  of the `EngineHandle` the MCP server holds — on the background executor,
  cancellable; it writes nothing. `code` cannot be checked. *Why:* the loop
  judges the final answer against the chunk.
- **D333 — what Save writes.** The shipped text with no row stores nothing;
  `based_on` keeps its value (only Keep mine moves it); a machine
  adaptation saved becomes `machine-reviewed` and keeps its source; a hand
  claim "adapted from L" records L and the hash of L's template as used
  now; nothing but the slot's row is written. *Why:* Reset is the road back
  to shipped, drift is acknowledged only by asking, and a save is a review.
- **D334 — a reset that breaks the step is refused.** When the other
  turn's stored override would break the rule beside the shipped text
  (the placeholder rule, in practice), Reset writes nothing and says to
  reset that turn first. *Why:* a step that does not render fails the job
  (`PipelineError::ShippedTemplate`).
- **D335 — what Adapt may replace.** Only an empty slot or one that is
  itself an adaptation; a template written in its own language is never
  replaced by a button. Temperature 0.3, seed 0, budget three times the
  source plus 128 tokens. Stored only when admitted. *Why:* a person's own
  writing is not overwritten by a click; an adaptation is a careful
  translation.
- **D336 — drift is shown, not merged.** Yours against today's shipped
  text as a line diff (`diff::Diff`); for a stale adaptation the source's
  change is shown when the old source was the shipped text (its hash
  matches), otherwise only today's source with a sentence that the earlier
  one is not kept. *Why:* the build carries only today's text and a hash of
  the past.
- **D337 — four variables.** The table lists `{TEXT}`, `{PREV_CONTEXT}`,
  `{PROTECTED}`, `{INTENSITY}` and says there is no variable for a
  language's name. *Why:* D64 dropped `{LANG_NAME}`/`{PIVOT_NAME}`; the
  register's table predates it.
- **D338 — the words of a check live in `prompts.rs`.** `reason_line`
  (a guard's reason) and `rejection_line` (the loop's rejection) are the
  app's; E4-6b can reuse them rather than write a second vocabulary.
- **D339 — the sample has three protected spans.** The inline command, and
  a link's markup on either side of its words (`⟦2⟧the runbook⟦3⟧`): that is
  how E4-1 prepares a Markdown link.

  the blocks — is for the owner's checklist below. Anything found there

  live gates on this host). Both are tested on the fake engine through the
  very `EngineHandle` road the page uses.

  decode) and shown as such; no test writes one, because the store has no
  API that writes text that is not JSON.

  so under the field rather than asking (a dialog for every slot change
  would be the louder mistake).

  gates ran, and had no commit after `2f7024d`, so there was nothing to merge again.
  `feat` had moved by plan commits only (`3b48986` … `74a4357`); it was not

  field and accessor on `Preferences`, `mod prompts;` in `main.rs`, the
  `## E4-6c` catalogue blocks).

   Rewriting). The banner, the variables table, the pivot row ("By the
   document's language") and the list of templates by language are there.
2. Russian › `paraphrase` › **user**. The field holds the shipped template;
   "The shipped template is in use."

   — {TEKST} is not a variable; did you mean {TEXT}? (line …, column …)".
   Press **Save**: "Not saved … Nothing was written." The list shows no
   "yours" beside the slot.
4. Put `{TEXT}` back, change a word, **Save**: "Saved." The slot's button
   reads "user — yours"; German › `paraphrase` › user says your change does
   not apply there.
5. With the machine's model on duty (Engine page), **Check template**: the
   sentence says it is a check and not a rewrite; while the model loads, the
   bar and the percent; then each step's answer, what the clean-up took
   off, every guard's verdict, the loop's verdict, tokens and time. Edit the
   field without saving and check again — the edited text is what was sent.
6. Change the pivot to German, close and reopen Settings — it stayed; back
   to "By the document's language".
7. German › `paraphrase` › user › **Adapt from Russian with the model**:
   "Adapted and saved, marked not reviewed"; the slot reads "adapted, not
   reviewed". **Save** once: "Saved, and marked reviewed."
8. Russian › user › **Reset to shipped**: the shipped text is back; German
   now says its Russian source changed after the adaptation.
9. Kill `wipemark` when done (port 5056).
