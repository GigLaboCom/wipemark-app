# Wipemark 0.1.1

A small fix on top of 0.1.0. Everything else is as in
[0.1.0's notes](0.1.0.md): what Wipemark does, how to install and uninstall
it, where your data lives, and what it cannot do yet.

## What changed

- **The list in the main window scrolls sideways.** In a window too narrow
  for every column, the right-hand columns, the Actions menu among them,
  used to sit past the edge with no way to reach them. A sideways swipe
  even scrolled the rows up and down instead. Now the column titles and the
  rows move sideways together. Three things move them:
  - a sideways swipe on a trackpad;
  - Shift and the mouse wheel;
  - the scroll bar along the bottom of the list.

  A sideways swipe no longer scrolls the rows up or down. The Name column
  keeps a usable width instead of shrinking to nothing. Where you scrolled
  to stays across page turns and filters. In a window wide enough for every
  column, nothing changes; that includes the window Wipemark opens at.

## Updating from 0.1.0

If you turned on **New versions** (Settings › General, or the first
launch's last step), Wipemark finds 0.1.1 within a day. **Check now** on
the same page finds it at once, with the setting on or off. A new version
is used only if its signature verifies.

- **`Wipemark.app` from the `.dmg`, or the AppImage**, in a folder you can
  write to, updates itself.
- **The `.deb`**, or a copy in a folder you cannot write to, says that
  0.1.1 is out and downloads it, verified, for you to install.

You can also install 0.1.1 over 0.1.0 by hand. Your settings, your list
and your models are kept.

## Install

| | file |
|---|---|
| macOS on Apple Silicon (M1 or later), macOS 12 or later | `Wipemark-0.1.1-arm64.dmg`, signed with a Developer ID and notarized |
| Linux x86_64, glibc 2.39 or later (Ubuntu 24.04, Debian 13, Fedora 40 and newer) | `Wipemark-0.1.1-x86_64.AppImage`, or `wipemark_0.1.1_amd64.deb` for Ubuntu and Debian |

The steps are those in [0.1.0's notes](0.1.0.md#install), with 0.1.1 in the
file names.
