# Список прокси регистра для русского — что `bench report` считает словом
# официального регистра, когда переписанный текст вводит его, а в исходном
# его не было (examples/bench/measure.rs, `register_new`;
# docs/architecture/prompt-bench.md, "Voice"). Это прокси, а не оценка:
# слово отсюда в контексте может быть простым, а текст может стать
# официальнее словами, которых здесь нет. Сравнивается только между
# прогонами на одном корпусе.
#
# Одна запись в строке, строчными буквами:
#   слово      само слово
#   основа*    любое слово, которое начинается с основы
#   -суффикс   любое слово, которое кончается суффиксом и в котором до него
#              не меньше трёх букв
# Слово считается, когда подходит под запись и ни одно слово исходного
# текста не начинается с тех же пяти букв (со всего слова, если оно короче):
# грубая основа, так что то же слово исходника в другом падеже — не сдвиг.
