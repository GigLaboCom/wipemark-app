# The register proxy's list for English — what `bench report` counts as a
# formal word when a rewrite brings in one the source did not have
# (examples/bench/measure.rs, `register_new`; docs/architecture/prompt-bench.md,
# "Voice"). A proxy, not a judgement: a word here can be plain in context,
# and a rewrite can turn formal with words that are not here. It is only
# ever compared between runs on the same corpus.
#
# One entry a line, lower case:
#   word      the word itself
#   stem*     any word that begins with the stem
#   -suffix   any word that ends with the suffix and has at least three
#             letters before it
# A word counts when it matches and no word of the source begins with the
# same five letters (the whole word, when shorter) — a crude stem, so the
# source's own word in another form is not a shift.
